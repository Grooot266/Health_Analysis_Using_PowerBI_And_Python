# Health_Analysis_Using_PowerBI_And_Python
The aim of the project was to do analysis on the data
collected through Google form based on the health problems of people. Analysis was
done according to particular region and diseases. Visualization of the data was done
using Microsoft Power Bi tool. In this project with the help of machine learning
algorithm we will predict an outcome from the collected data. Machine Learning algorithms are the programs that can learn the hidden patterns from the data, predict
the output, and improve the performance from experiences on their own.


This project it is divided into two part:- 
The first phase of project was to visualization of real time data which was collected from google form based on which insights were gathered through PowerBI.
You can find out the various insights which was drawn in the report by simply open the "Health analysis final.pbix".
To open the above mentioned file you must have PowerBI desktop installed in your Laptop/PC. 
Also you can view it's pdf file.

The second phase of this project was based on previously collected data from google form and create a machine learning model to predict the health using python & flask
In this the jupyter notebook is been used , you can view the file by opening "Health analysis ML project.ipynb" in jupter notebook or google colab or visual studio code in your laptop / PC.
Through this python A pickel file is created as "model.pkl" which has been used to deploy the machine learning model which has been created to the website for it's better understanding.
Simply open app.py in your laptio/pc through visual studio code or pycharm, Install the various python library which are needed and run the app.py file.
